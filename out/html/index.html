Ontologia do Portal da Transparência do ES OPTES

Propósito: O propósito da ontologia é representar os conceitos relacionados aos dados publicados no Portal da Transparência do Poder Executivo do Estado do Espírito Santo, bem como os conceitos necessários à interpretação dessas informações, considerando os diferentes domínios de informação governamental e os elementos conceituais compartilhados entre eles (what); de modo a estabelecer uma conceituação explícita e compartilhada que apoie a compreensão das bases por usuários humanos, a integração semântica entre diferentes conjuntos de dados e a posterior representação dos dados por meio de tecnologias da Web Semântica (for what); visando reduzir ambiguidades na interpretação dos dados, favorecer sua interoperabilidade semântica com dados internos e externos e ampliar as possibilidades de integração, consulta e reutilização automatizada das informações publicadas (why).

Esta ontologia está estruturada em módulos para melhor organização e reutilização de conceitos. Abaixo estão disponíveis os links para acessar a documentação detalhada de cada módulo específico gerada via pyLODE:

  • Módulo nucleo (nucleo)
    O subdomínio nucleo reúne requisitos relacionados a conceitos que podem ser compartilhados por diferentes conjuntos de dados do Portal da Transparência.
  • Módulo base-receitas (base-receitas)
    O subdomínio base-receitas visa estabelecer os conceitos centrais necessárias para compreender o que é uma receita pública e como conceitos relacionados estão envolvidos, especialmente as Unidades Gestoras.
  • Módulo base-despesas (base-despesas)
    O subdomínio base-despesas visa estabelecer os conceitos centrais necessárias para compreender o que é uma despesa pública, quais são seus subtipos e como conceitos relacionados estão envolvidos.
